# screen s1ze

A clean and fluid Flutter application designed to provide detailed information about your device's display.

## Features

"screen s1ze" helps you collect and view essential display metrics, including:

-   **Screen Dimensions:** Get the precise width and height of your screen.
-   **Safe Area:** Understand the usable screen space, accounting for notches, status bars, and other system intrusions. View the size and offset of the safe area.
-   **Navigation Bar Size:** See the current size of the navigation bar.
-   **Screen Corner Radius:** Check the corner radius of your device's screen.
-   **Display Capabilities:**
    -   **Color Gamut:** Details about the display's color space.
    -   **Refresh Rate:** Supported refresh rates of the screen.
-   **Orientation:** View how screen dimensions change with device orientation.

## Design

The app's design philosophy is centered around a **clean, modern, and fluid** user experience. It incorporates:

-   **Visually Balanced Layouts:** Clean spacing and modern components for an intuitive interface.
-   **Expressive Typography:** Clear and hierarchical text to make information easy to digest.
-   **Vibrant & Interactive UI:** A rich color palette and interactive elements with subtle effects to create a premium feel.
